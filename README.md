# discord_archive

`discord_archive.py` turns a folder of [DiscordChatExporter](https://github.com/Tyrrrz/DiscordChatExporter) (DCE) exports into a static archive. The result works offline (open `index.html` from disk, no server needed) or can be hosted on GitHub Pages or Cloudflare Pages.

## Install

Python 3.10+ is enough for JSON exports. To parse DCE HTML exports as well:

```bash
pip install -r requirements.txt
```

## Usage

```bash
# 1. Export with DiscordChatExporter's CLI, using a bot token, and save media so images survive:
#    DiscordChatExporter.Cli exportguild -t BOT_TOKEN -g GUILD_ID -f Json --media --reuse-media -o export/
# 2. Build the archive:
python discord_archive.py export/ site/ --title "My Server Archive" \
       --anonymize --redact-contacts --drop-system --exclude-users 1234,5678
```

- Input: DCE JSON (preferred) or DCE HTML (best effort). Overlapping exports are merged, de-duplicated by message ID, and sorted by time.
- Output: `index.html` (channel list plus full-text search via an embedded `search_index.js`), paginated channel pages (`--page-size`, default 300), `media/`, `data/*.json`, and `report.txt`.
- `report.txt` lists attachments that exist only as expiring Discord CDN links. Re-export with `--media` to save those files.

## Permission and privacy

Only archive servers you own or administer, or where you have explicit permission. Use a bot token that belongs to that server. Do not use user tokens or self-bots; those violate Discord's Terms of Service.

Respect member privacy. Tell the community before you publish an archive, and offer an opt-out. Pass opted-out user IDs with `--exclude-users`. For anything public, use `--anonymize` (stable pseudonyms such as "Otter 3f2a") and `--redact-contacts` (emails and phone numbers).

Known gap: names typed in plain text are not anonymized (for example, "thanks Sam!"). Spot-check before you publish, or keep the archive private.

Leave NSFW channels out of the export unless you explicitly want them, and do not host them publicly.

## Sample data

All usernames, messages, emails, phone numbers, and images in `synthetic_export/` and `demo_archive/` are synthetic. They were generated by `make_synthetic.py` and are not from a real Discord server.

```bash
python make_synthetic.py

```

`demo_archive/` and `demo_screenshot.png` were built from that synthetic export.

## Limitations

- HTML mode cannot resolve user mentions, because DCE HTML does not carry the ID map. Prefer JSON.
- Plain-text names are not anonymized (see above).
- Threads and forum channels come through as separate channel files with no parent link.
- Tested so far against synthetic DCE-shaped JSON and HTML, not yet against a live server export.

HTML class names match DCE's MIT-licensed `MessageGroupTemplate.cshtml`.
